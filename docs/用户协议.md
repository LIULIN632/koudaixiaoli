## 一、应用性质

「口袋小鲤」是烟台理工学院学生自主开发的**非官方**校园辅助工具，完全开源（GPL-3.0），无广告、无付费、不接入任何第三方广告或统计 SDK。

本应用不隶属于、不代表烟台理工学院或其任何部门，也不代表任课教师。课表、成绩、考试等信息**一律以学校官方系统与教务通知为准**。

## 二、权限与数据来源

应用的权限都**按需逐项申请**，全部由您自行决定是否授予；拒绝某项权限只影响对应功能：网络（全部在线功能）、通知（更新与上课提醒）、日历读写（把课表写进系统日历）、相机（扫位置二维码）、蓝牙（发现附近热水器，仅 Android 12 及以上且只在您主动扫描时申请）、精确闹钟与开机自启（确保课程提醒准时）、前台服务（专注计时在后台继续）、安装未知应用（应用内更新时交给系统安装器）。

导入、导出文件走**系统文件选择器**，应用不申请存储权限，也只读得到您在那一屏亲手选中的文件。

教务数据（课表、成绩、考试、空教室等）通过 HTTPS **直接访问学校现有系统接口**获取，请求从您的设备发起，不经过开发者服务器；开发者也不保存任何一份。

账号密码经 Android Keystore 加密后**仅保存在本机**（EncryptedSharedPreferences，AES-256-GCM），不会上传，也不会出现在日志里。

## 三、本机数据与诊断

课表、成绩、待办、资料下载记录、AI 配置与聊天记录等，全部保存在本机。卸载应用或清除数据会一并删除，请自行备份重要内容。

崩溃日志与诊断报告**默认只写在本机**，是否导出、发给谁，由您决定；应用不会自动上传。

匿名运行统计（可在「我的 → 设置 → 关于 → 隐私」关闭）：只统计启动、更新提示、点击更新、下载完成、安装完成、崩溃次数这几类**计数**与版本号，不含设备标识、学号、课表或任何内容；统计用的随机标识每 30 天更换一次，没有接口能按它查到具体的人；关闭后本机**不再写入**任何统计队列。

## 四、AI 功能（鲤鱼）

鲤鱼的对话能力由您自行配置模型服务与 API Key，Key 加密保存在本机。不配置也能使用查询、课表等本地能力。

使用对话时，您的问题、上下文、工具查询结果与附件摘要会发送到**您选择的模型服务商**（或您填写的中转服务）。是否使用、用哪家、发什么，完全由您决定；请勿提交不希望第三方处理的个人信息。

AI 的回答可能不准确，涉及成绩、选课、考试等重要事项时请以学校系统与老师答复为准。
