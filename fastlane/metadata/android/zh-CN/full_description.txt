口袋小鲤是烟台理工学院学生自主开发的非官方校园助手，用 Kotlin 与 Jetpack Compose 原生实现。

功能
- 首页：下一节课倒计时、待办与考试、天气、全局搜索、消息（更新 + 公告）
- 课表：周课表、调停课、当前周切换、导入导出（ICS / 图片 / 系统日历）
- 鲤鱼（AI 助手）：自行配置模型与 Key，查课表、成绩、空教室、天气；工具可单独开关
- 服务：成绩与修课查询、选课、空教室、教师查询、图书馆、热水、快递、校园卡、资料站、快问快答
- 校园地图：全屏 3D 沙盘、楼栋档案与分层平面图、教室搜索、导览

隐私
- 课表、成绩、待办等只存本机，系统云备份默认关闭
- 学号与密码用 Android Keystore 加密后仅存本机
- 无第三方广告 / 统计 / 推送 SDK
- 本版本（F-Droid 构建）不包含匿名运行统计，也不带应用内更新

说明
- 非官方项目，不代表学校；课表与成绩以学校系统为准
- 本应用只服务烟台理工学院
